# Jira Comment Signals

## 使用定位

本文件只提供 Jira 评论中的检索和标注信号，用于提醒必须回读上下文、日志、关联票和正式资料；不定义评论权重、来源优先级、结论门槛或表格写法。上述规则唯一以 `agent/evidence-contract.md`、`agent/output-contract.md` 和 `agent/sheet-contract.md` 为准。

## 必须提升为核心证据的评论

- `需要产品确认`
- `需要产品定义`
- `需要产品确定`
- `UI 不参与页面优先级定义`
- `研发不定义这个逻辑`
- `设计如此`
- `历史如此`
- `从 8295 / 8155 迁移过来就是这样`
- `如果要调整，需要下需求`
- `客户已接受`
- `客户接受现有方案`
- `测试提供用例来源`
- `无需求 / 无文档定义`

## 使用动作

- 命中信号后，按时间线提炼完整因果链，识别是否出现问题链接、共享日志、重复票或测试预期冲突。
- 命中“设计如此 / 历史如此 / 无需求”等信号时，继续检索同范围的正式定义或客户最终结论；评论本身不能直接关闭。
- 命中“客户接受现有方案”时，识别是否为会议/复盘材料，并按 `agent/workflows/review.md` 处理；未获用户授权不评论、不流转 Jira。
