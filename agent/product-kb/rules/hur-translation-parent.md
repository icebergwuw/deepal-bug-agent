## 适用

只处理同时满足这些条件的票：

- 项目是 HUR，类型是故障，不是故事。
- 当前经办人是 `you.wu`，状态未完成。
- 现象是翻译、文言、译文、Text ID 或页面文案和翻译表不一致，包括译文缺失、译文错误、翻译换行、翻译截断和显示不全。

不适用：语音执行失败、query 未执行、TTS 被状态退出截断、故事票、已关闭票，以及其他负责人的票。摘要里出现「截断」不能单独当成翻译票。

## 总票

当前总票只记录在 `agent/context.md`。执行前回读该票仍未完成，且仍是收翻译问题的故事。用户给出新总票，或记录中的总票已关闭、已解决、不再收翻译问题时，先改 `agent/context.md` 再关联。不得沿用历史票号，也不得在流程正文把某个票号写成永久值。

## 动作

1. 原 Bug 用 Relates 关联当前总票。已关联不重复建。
2. 原 Bug 评论写明翻译问题、当次实际关联的总票链接，以及按 workaround / bug转需求关闭。
3. 原 Bug 解决结果用 Workaround。需要时先进入处理中再解决。保留原修复版本、QA 和严重程度，不改经办人。
4. 回读状态、解决结果、关联和评论。未回读不得说已关闭。

这类不新建单张需求，不写变更管理表，不发飞书建票通知，不回填吴优 bug 表。译文缺失的根因用需求遗漏；和翻译表不一致的根因用需求变更。
