# Bug Handling Categories

## 非问题 / 关闭

- 没有需求定义。
- 测试预期无来源。
- 当前行为符合 PRD / UE / 配置表。
- 用户语义不成立，例如 `设置` 不等于 `打开`。
- 数字显示、翻译期望属于测试理解偏差。

## 修改用例 / 转测试

- 功能本身正确，但测试用例写错。
- 用例前置条件和需求不一致。
- 测试把不支持能力当成应支持。

## Debug / 转研发

- 有需求定义，车端未按要求执行。
- 页面 key / 映射 / 状态未按定义展示。
- 下发正确但执行错。

## 转语音 / NLU / 运营平台

- 语音落域错。
- query / 泛化 / 槽位缺失。
- TTS 文案或文案选择错误。
- Alchemy 项目点未继承或项目执行策略缺失。

## 转需求

- 新语料、新规则、新前置条件、新系统协同。
- 当前历史设计要改体验。
- 合理用户预期但无现有定义。

## 重复问题

- 与已有票同根因，保留代表票，其他票关联或关闭。
