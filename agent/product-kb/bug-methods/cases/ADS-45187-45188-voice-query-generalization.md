# ADS-45187 and ADS-45188 Voice Query Generalization

## 基本信息

- 模块：语音 NLU / 算法配置 / 运营平台
- 共同模式：原话语义已被既有深蓝功能点覆盖，但在线分类落到 `1919 common:func:not:supported`。
- 处理原则：补语义泛化到既有 `meta_id` 和深蓝项目功能点，不新建功能点。

## ADS-45187：擦车模式

- Jira：`http://jira.i-tetris.com/browse/ADS-45187`
- VOS 原话：`进入擦车模式`；在线识别正确，但落 `1919`。
- 对照测试：`进入洗车模式`、`打开洗车模式`均命中 `meta_id=1127`，`vehicle:scenario:ctrl`，`mode=car_wash_mode`。
- 标准功能：`1364 打开特定情景模式`。
- 深蓝项目功能点：`24510`，已支持洗车模式；现有泛化仅有“自动洗车模式”。
- 产品结论：语音 NLU/算法配置补“擦车模式”到既有洗车模式，复用 `1127/24510`。

## ADS-45188：当前导航目的地

- Jira：`http://jira.i-tetris.com/browse/ADS-45188`
- VOS 原话：`现在我导航的地址是哪里呀`；在线识别正确，但落 `1919`。
- 对照测试：`现在目的地是哪里`命中 `meta_id=1015`，`navi:query:journey:info`，`topic=dest`。
- 标准功能：`1087 查询当前目的地`，示例包含“我们现在导航去哪里来着？/现在目的地是哪里？”。
- 深蓝项目功能点：`24315`，继承未修改，当前支持高德地图。
- 产品结论：语音 NLU/算法配置补该问法到既有当前目的地查询，复用 `1015/24315`；回归须在导航中验证目的地 TTS。

## 可复用规则

- 日志原话先跑在线对话；若原话拒识，但语义等价的标准问法命中既有功能点，应以标准功能和深蓝项目功能点为准，补 NLU 泛化。
- 只有功能点或项目支持范围不存在时才转新需求；已有标准功能和项目继承点时不得重复新建。
- 对地图查询类泛化，除意图命中外必须保留导航中/非导航中两种回归；项目支持地图范围由项目功能点决定。
