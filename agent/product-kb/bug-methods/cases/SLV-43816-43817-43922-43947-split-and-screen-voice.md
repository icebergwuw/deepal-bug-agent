# SLV 分屏与屏幕角度语音判断

## 适用范围

李欣前 10 条中涉及非华为应用外分屏、分屏退出/全屏，以及副驾屏角度语音控制的同类问题。

## 证据

- Jira：SLV-43947、SLV-43923、SLV-43922、SLV-43924、SLV-43820、SLV-43817、SLV-43816。
- 正式定义：[8155平台_应用外分屏（非华为配置）_功能定义_V0.1.pdf](https://drive.google.com/file/d/1DEWhGGFk1vPxT5cEpAa680OHQEk1Vx0r)。
- Alchemy 关闭分屏：SLV 在线 `meta_id=3033`，标准功能 1748，深蓝项目点 26815，项目点继承未修改。
- Alchemy 收起屏幕：SLV 在线 `meta_id=1421`，标准功能 1000，深蓝项目点 24285，项目点继承未修改。
- Alchemy 展开屏幕：SLV 在线 `meta_id=1418`，标准功能 1003，深蓝项目点 24288，项目点继承未修改。

## 可复用产品规则

1. 正式分屏定义优先于 Jira 中“非华为没有需求”的口头判断：地图桌面 widget 不得与应用外分屏同时展示；重新打开当前参与分屏的应用时应退出分屏并使目标应用全屏；语音关闭分屏属于已有能力。相关问题转 SystemUI/Launcher 与媒体/车端执行处理，不按 Invalid 关闭。
2. `关闭分屏` 已命中现有标准功能和深蓝项目功能点，NLU 不需要新建功能点；若播报车型不支持，先查 C673 项目执行路由与车端执行。
3. `收起屏幕` 的深蓝项目点明确了前提条件和不支持 TTS。若现场满足右前门打开且副驾屏角度在 5°~135°，现状可能符合项目策略；Jira 缺少现场条件时先补条件再复核。
4. `展开一点屏幕` 命中已有 `meta_id=1418`，不应先判为 ASR/NLU 缺陷。当前项目点继承标准且无现行自定义 TTS，历史曾有“小于 110°”条件说明；需先定当前条件、动作和 TTS，再拆分语音配置与车端执行问题。

## 责任边界

- 分屏页面层级、widget、退出/全屏：SystemUI/Launcher；媒体应用配合联调。
- 关闭分屏的实际执行：车端执行/CarSettings/Launcher；语音平台只负责已有功能点命中和项目配置核对。
- 副驾屏角度的条件与 TTS：先按深蓝项目功能点核对，条件不满足时再转车端执行排查。
