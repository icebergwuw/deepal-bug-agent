# ADS-45852 Big Model Card Dismissal

## 基本信息

- Jira：`http://jira.i-tetris.com/browse/ADS-45852`
- 模块：大模型卡片 / Voice UI / 车控
- 关联案例：`SLV-43932`

## 产品定义

普通车控成功执行后不自动关闭大模型卡片，避免用户因一次执行结果丢失当前对话上下文和后续操作入口。

仅在以下情形退出或切换卡片：

- 用户显式取消；
- 卡片自身超时；
- 操作需要拉起目标应用或目标页面，且目标页面应优先展示。

## 处理方式

无明确 UE/PRD 要求普通车控后自动关闭时，按上述产品定义关闭无效 bug；若后续要调整，按 Voice/UI + SystemUI 的页面层级需求处理。
