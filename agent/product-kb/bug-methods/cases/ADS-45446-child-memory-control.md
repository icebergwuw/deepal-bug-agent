# ADS-45446 儿童记忆 ID 与车控能力边界

## 基本信息

- Jira：`http://jira.i-tetris.com/browse/ADS-45446`
- 模块：Megaclaw / 记忆空间 / 车控
- 问题：记忆 ID 标记为儿童后，仍可执行车控相关 query。

## 证据

- Jira 未提供原始车控 query，仅描述“车控相关指令”仍可执行。
- Jira 研发评论说明记忆 ID 是深蓝/字节记忆域能力，与 Mega 车控域无关联；三方评审后要求给出产品结论。
- 记忆空间 PRD 仅定义儿童 ID 的儿童对话模式和记忆范围，未定义儿童状态拦截车控。

## 产品处理结论

- 关闭无效 bug：儿童记忆 ID 不拦截普通车控。
- 若后续需要儿童安全限制，单独转需求定义车控白名单、拦截范围、解除机制和原始 query 覆盖范围。

## 可复用规则

1. 一个功能域的儿童/身份状态不会自动扩展为另一功能域的安全限制。
2. 未在 PRD 定义的跨域限制不得以“应当更安全”为由直接判为 bug。
3. 没有原始 query 时，不能假设所有车控类型或执行条件；按已定义能力边界处理。
