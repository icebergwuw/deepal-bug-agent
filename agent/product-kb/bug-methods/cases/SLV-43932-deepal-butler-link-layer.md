# SLV-43932 Deepal Butler Link Layer

## 基本信息

- Jira：`http://jira.i-tetris.com/browse/SLV-43932`
- 模块：深蓝管家 / Voice UI / SystemUI 页面层级
- 关键词：深蓝管家、链接、弹窗消失、AppList、页面优先级、产品定义

## 问题

在功能页面问深蓝管家的问题，点击链接后弹窗消失。

## 关键评论

- Voice/UI 反馈点击按钮消失卡片是历史设计，从 8295 迁移过来就是这样。
- AppList 层级较高，会盖住应用；如需调整需要产品下需求，并和 SystemUI 讨论方案。
- UI 反馈不参与页面优先级定义，需要产品确定。

## 产品结论

点击深蓝管家链接后应优先完成链接跳转 / 目标页展示，不应仅因 AppList 层级直接关闭卡片。

## 处理方式

转需求给 SystemUI + Voice/UI，补页面优先级和弹窗关闭策略。

## 可复用规则

评论出现“页面优先级需要产品定义”时，不能写“是否接受现状”。用户要求 Codex 判断时，直接给产品定义、责任方和下一步。
