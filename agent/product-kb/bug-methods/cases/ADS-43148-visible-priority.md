# ADS-43148 Visible Node Priority

## 基本信息

- Jira：`http://jira.i-tetris.com/browse/ADS-43148`
- 模块：语音 / 可见即可说 / 3D 车模
- 关键词：可见节点、关闭、多个结果、优先级、产品定义

## 问题

空调设置界面 query `关闭`，只有一个可见按钮时 TTS 仍询问选择第几个。

## 关键依据

罗稚钦表记录：3D 车模应用同时上报了两个响应“关闭”语义的可见节点，导致语音系统触发多目标歧义询问；需要产品确认类似问题如何修改 priority，并同步修改可见文档。

## 产品结论

需要增加产品优先级定义，由可见可说开发提供优先级配置方式，应用侧逐个适配。

## 可复用规则

可见即可说出现多个同语义节点时，不只判断为语音 bug；要查页面上报节点、产品优先级定义和应用适配责任。
