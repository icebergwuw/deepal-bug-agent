# ADS Memory Space and Celebration Rules

## 适用范围

- Jira：`ADS-46286`、`ADS-46576`、`ADS-46307`、`ADS-46295`、`ADS-46282`、`ADS-45200`、`ADS-45717`、`ADS-45982`
- 模块：记忆空间、声纹识别、儿童对话、生日庆生
- 主要资料：记忆空间 PRD

## 可复用产品规则

### 庆生与挡位

- 非 P 档触发庆生只执行语音链路，不展示庆生画面、屏幕旋转或“结束庆生”按钮。
- 庆生退出的挡位条件是从 P 档切至非 P 档；挂入 P 档不是退出条件。
- 生日字段非必填，默认空；只有填写生日后才参与生日庆生。

### 儿童与声纹

- 已录入声纹且开启儿童对话的儿童，命中记忆 ID 后应按昵称问候；儿童童趣音色在当前 V0.6 范围内不支持，不能以音色判错。
- 同一上电周期首次唤醒时，已匹配记忆 ID 的声纹应按昵称问候。
- 记忆 ID 创建页和详情页的声纹录入入口应复用同一录入流程，任一入口无响应均由声纹识别/记忆空间处理。

### 记忆 ID 生命周期

- 创建记忆 ID 和声纹录入全程要求 P 档；非 P 档禁止开始录入并播报停车提示。
- 新建记忆 ID 的 AI 深蓝记忆服务默认开启；删除 ID 时须清理其服务开关和关联记忆数据，重建不得继承已删除 ID 的状态。

## 责任边界

- 昵称问候、声纹匹配、录入入口：声纹识别 / 记忆空间 / DEEPAL AI 情感化语音。
- P 档拦截、删除后状态清理：记忆空间研发。
- 非 P 档庆生、生日非必填、挂入 P 档退出：按上述 PRD 关闭无效 bug，不额外转需求。
