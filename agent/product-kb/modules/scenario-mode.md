# Scenario Mode

来源：`深蓝情景模式车型配置_20250516`，页签 `情景模式`。

## 表结构

- `功能`
- `前置条件`
- `TTS`
- `备注`
- 车型列：如 `673-6`、`385-2`、`385基础车&385ICA&DA`、`673基础车`、`385MCA`、`673ICA`

## 样例规则

| 功能 | 前置条件 | TTS | 车型支持 |
| --- | --- | --- | --- |
| 打开冰雪木屋 | 冰雪木屋未安装 | 冰雪木屋需要安装应用后才可以使用哦 | 多车型支持 |
| 打开冰雪木屋 | 挡位不为 P 挡 | 请先切换到 P 挡后再开启 |  |
| 打开篝火星辰 | 电量小于等于 20% 且车辆未充电 | 电量不足，无法开启篝火星辰 |  |
| 打开车内关怀模式 | 摄像头权限未授权 | 请先对摄像头授权后，再开启车内关怀 | 部分车型支持 |

## 使用规则

- 情景模式 bug 先查功能是否支持当前车型。
- 再查前置条件和 TTS 是否已有定义。
- 如果平台 / 应用缺少已定义前置条件，转语音平台或应用侧补条件。
- 如果表内没有该前置条件，但用户预期合理，按 bug 转需求处理。
- 长马语音语料只查 `agent/context.md` 的 `OTA节点_J90A-标准语料_V1.0`。小憩调时长英语在 `1_英语` 的 `mode_05`，必须已进入小憩编辑态，否则静默。露营调时长英语 `mode_08` 在 2026-10-23 核对时整组写成了 rest mode，不能把这组当成露营目标说法。
- 语料原 Bug 关票是一定的。转需求 story 按 `rules/hur-translation-parent.md`：未传递给开发、经办人仍是 `you.wu` 就复用，已传递给开发才新建。同一小憩或露营问题不逐张新建。
