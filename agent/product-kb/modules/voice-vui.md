# Voice / VUI / AIS

## 范围

- VUI：可见即可说、页面交互控制、语音执行错误。
- 语音服务：语音链路、服务层能力。
- AIS：ASR、语音服务 SDK、算法能力。
- TTS：播报文案、文案选择、差异化回复。

## 固定链路

1. 用用户原话去 Alchemy 在线对话测试。
2. 记录 `classification`、`operations`、`meta_id`、槽位、`visible_result`、`llm_data_result`。
3. 用 `meta_id` 查标准功能。
4. 如果有项目继承点，继续查深蓝项目功能点。
5. 再判断落点：ASR、NLU/标注、DS/功能点、项目执行策略、TTS、车端执行、新需求。

## 判断规则

- ASR 将用户原话识别成错误文本，确认属于语音识别错误后，统一转汪文菁处理。
- 平台已有能力但 query / 槽位 / 项目继承缺失：转语音/NLU或运营平台，不直接新建需求。
- 标准功能不支持合理用户预期：转需求。
- 下发正确但车端执行错：转应用研发。
- 执行正确但 TTS 错：转 TTS / 运营平台文案。
- 可见即可说问题要查页面上报节点和优先级，必要时拉应用侧一起处理。
