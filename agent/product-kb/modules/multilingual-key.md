# Multilingual Key / All Key

来源：`J90A_AllKey_静态补齐多语言_最终检查版`。

## 典型页签

- `All Key`：Key 值、版块、文本编号、中文、多语言列。
- `01_3D Control`：页面截图、页面 ID、页面路径、文本 ID、Key 值、文本、含义备注。
- `UE_list` / `History`：UE 和历史检查。

## 使用场景

- 多语言显示问题。
- 文案 key 缺失或映射错误。
- 页面文本和翻译不一致。
- 语音 TTS / 页面显示之间的文本来源确认。

## 判断规则

- 先区分是“翻译错误”“key 映射错误”“测试预期错误”还是“产品需求缺失”。
- 如果中文和需求定义一致，只是测试期望不同，优先按非问题 / 修改用例。
- 如果已有 key 但外语文案错误，转多语言 / 文案修复。
- 如果页面使用了错误 key，转对应应用研发修映射。
