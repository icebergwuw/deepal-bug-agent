# 2026-07-22 Jira评论来源链接规则

## 用户要求

- Jira评论引用PRD、UE、Alchemy或工作说明得出结论时，必须附对应原始可访问链接，不能只写结论。
- 没有可访问来源时，简要说明来源限制。

## 更新位置

- `AGENTS.md`：证据与外部动作总则。
- `agent/workflows/bug.md`：实际评论、评论草稿和交付前检查。
- `agent/workflows/review.md`：复盘与会议生成的Jira评论草稿。

## 执行口径

- 引用多个来源时逐个附原始链接。
- 只有资料名称、二手转述或不可访问入口，不算完成证据引用。
- 无法访问时说明具体限制，不把该来源写成已核实证据。

## 外部动作

- 本次仅更新本地规则和日志，未评论或修改任何Jira。
